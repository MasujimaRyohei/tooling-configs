# gitignore Templates

Project-type specific `.gitignore` templates. Copy the one that matches your project.

| File              | Use for                         |
| ----------------- | ------------------------------- |
| `node.gitignore`  | Node.js, generic JS/TS projects |
| `react.gitignore` | React (Vite, CRA, etc.)         |
| `next.gitignore`  | Next.js                         |
| `expo.gitignore`  | Expo / React Native             |

## Usage

```bash
cp node.gitignore /path/to/your-project/.gitignore
```

Or merge with existing:

```bash
cat next.gitignore >> /path/to/your-project/.gitignore
```
